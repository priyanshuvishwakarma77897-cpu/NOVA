
# NOVA

A customizable personal AI assistant.

NOVA is the temporary project name. The assistant's actual name will be configurable by the user.

## Project Goals

- Natural text-based conversations
- Optional voice interaction
- Customizable assistant identity and personality
- Long-term memory with user controls
- Secure, permission-based tool execution
- Desktop application management
- Responsive web interface

## Technology Stack

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript

### Backend
- Python
- FastAPI
- Uvicorn

### Database
- SQLite (initial development)

## Architecture

The project uses a modular monolithic architecture.

The frontend and backend are maintained separately, with FastAPI serving the frontend during initial development.
